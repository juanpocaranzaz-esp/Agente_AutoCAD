# AutoCAD 2021 (English) Technical Invariants

1. **AutoLISP in Headless Mode (accoreconsole):**
   - Do NOT use GUI ActiveX methods (`vla-*`, `vlax-get-acad-object`) in headless mode. Many COM interfaces and GUI-dependent dispatchers fail in `accoreconsole.exe`.
   - Use standard AutoLISP functions: `entget`, `tblnext`, `tblsearch`, `ssget`, `trans`, `entmake`, `entmod`.
   - If using `vl-string-*` functions, always call `(vl-load-com)` at the start of the script.
   - Always enforce `(setvar "DIMZIN" 0)` and leading-zero formatting (`num-json`) before calling `(rtos ...)` when serializing numeric data to JSON so leading zeros (`0.25`, `-0.25`) are never suppressed (`.25`, `-.25`).
   - Dynamic block effective names must be resolved by checking the `INSERT` entity extension dictionary first, then falling back to the `BLOCK_RECORD` extension dictionary (`AcDbBlockRepresentation` -> `AcDbRepData` / `AcDbBlockRepETemplate` / `AcDbBlockRepBTag` -> `DXF 340` or `DXF 1005`), and finally DXF group 2.

2. **AutoLISP Sandbox & Circuit Breaker:**
   - AutoLISP routines generated by the agent must NEVER invoke OS-level, command-shell, binary-loading, arbitrary evaluation, or external file-manipulation functions:
     Forbidden: `startapp`, `_.SHELL`, `_.SH`, `arxload`, `arxunload`, `autoarxload`, `netload`, `autoload`, `vl-load-all`, `vl-file-*`, `vl-registry-*`, `vl-mkdir`, `dos_*`, `eval`, `read`, `vla-eval`, `vla-runmacro`, `vla-loaddvb`, `vla-loadarx`, `vl-vbaload`, `vl-vbarun`, `vlax-invoke`, `vlax-invoke-method`, `vla-sendcommand`, `setenv`, `Scripting.FileSystemObject`, or opening files for writing/appending `(open ... "w")`.
   - Opening files with `open` is strictly restricted to literal read-only calls: `(open <expr> "r")`.
   - Loading reusable scripts via `skill_script` or `(load "...")` is ONLY permitted when targeting existing `.lsp` scripts inside approved roots (`.agents/skills/`, `lisp-library/`, and `ACAD_EXTRA_LISP_DIRS`).
   - The Python server verifies structural balance (parentheses, quotes, comments), strips comments, and automatically rejects any code matching forbidden patterns before sending it to AutoCAD.

3. **Coordinate Transformation Invariant (OCS to WCS) & UCS Alignment:**
   - DXF group 10 for `TEXT`, `INSERT`, and vertices in `LWPOLYLINE` are stored in Object Coordinate System (OCS).
   - If DXF group 210 (extrusion vector) is present, coordinates MUST be converted to WCS via `(trans pt norm 0)`. If 210 is absent, the default extrusion is `'(0.0 0.0 1.0)`.
   - Note that `MTEXT` stores `DXF 10` directly in World Coordinate System (WCS) and must NOT be transformed using OCS extrusion.
   - For aligned/centered `TEXT` (`DXF 72 /= 0` or `DXF 73 /= 0`), use `DXF 11` for the visual insertion point.
   - Headless mutating scripts conditionally preserve the user's UCS, setting `(command "_.UCS" "_World")` only when necessary and restoring `(command "_.UCS" "_Previous")` before saving.
   - Always record entity space: DXF group 67 (`0` or absent = Model Space, `1` = Paper Space) and DXF group 410 (Layout tab name).

4. **International Non-Modal Commands:**
   - Every AutoCAD command in scripts (`.scr`) or `(command ...)` MUST use underscore `_` and hyphen `-` where applicable: `_-LAYER`, `_-INSERT`, `_-STYLE`, `_-PURGE`, `_-PLOT`, `_.ZOOM`, `_.QSAVE`, `_.AUDIT`.
   - Never invoke commands that trigger modal dialog boxes. Always set `FILEDIA 0` and `CMDECHO 0`.

5. **Security & Trusted Paths Guard:**
   - Always set `SECURELOAD 0` in headless scripts before calling `(load ...)` to prevent AutoCAD from refusing to load AutoLISP files from workspace folders.

6. **Entity Creation, OSNAP Hygiene & Error Handler Preservation:**
   - Both `mutate_cad_headless` and `execute_cad_live` automatically enforce `(setvar "OSMODE" 0)` and `(setvar "DIMZIN" 0)` before running your AutoLISP code, manage the global `*error*` handler (`*mcp_err_flag*`), and restore the drawing's original OSMODE and DIMZIN settings upon completion or error.
   - Do NOT redefine `(defun *error* ...)` in ad-hoc routines, as doing so would overwrite the MCP rollback guard `*mcp_err_flag*`. If a custom error handler is strictly needed inside a function, it MUST include `(setq *mcp_err_flag* T)` and print `[MCP_LISP_ERROR]`.
   - Prefer `(entmake ...)` over `(command ...)` for deterministic geometry generation.

7. **Headless Persistence & Integrity:**
   - Every headless mutating script must check `(logand (getvar "CMDACTIVE") 3) > 0` to clean up hanging commands (ignoring accoreconsole script bit 4), verify errors via `*mcp_err_flag*`, run `(command "_.AUDIT" "_Y")` and `(command "_.QSAVE")`, and verify `(= (getvar "DBMOD") 0)`.
   - Console command warnings (`Unknown command`, `Invalid option keyword`) trigger an immediate error status and automatic rollback.
   - Failed headless mutations automatically roll back to the pre-mutation state using atomic replacement (`os.replace`) and clean up the temporary backup copy so no spurious `-Legacy-N` files remain.

8. **Spatial BBox, Pure-AutoLISP Takeoffs, Diffing & Headless Plotting (v1.4.8):**
   - Spatial filtering (`MCP_BBOX`) and curve metric calculations (`MCP_TAKEOFF` for `LINE`, `LWPOLYLINE` with bulge arcs, `CIRCLE`, `ARC`) execute in standard AutoLISP (`entget`) without ActiveX dependencies.
   - Headless plotting uses international non-modal `_.-PLOT` with `FILEDIA 0`, `CMDECHO 0`, and `BACKGROUNDPLOT 0`.
